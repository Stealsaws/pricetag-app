# RIKIRIKI ป้ายราคา — ระบบพิมพ์ป้าย (v1)

เว็บแอป static (ไม่ต้อง build/Node) สำหรับกรอกข้อมูลสินค้าแล้วพิมพ์ป้ายราคา/โปรโมชั่น
ตามเทมเพลตทั้ง 16 แบบที่ทีมออกแบบไว้ (4 หมวด × 4 ขนาด)

## วิธีเปิดใช้งาน (ทดสอบในเครื่อง)

เปิดตรงจากไฟล์ (`file://`) จะโหลด `data/templates.json` ไม่ได้เพราะเบราว์เซอร์บล็อก
ต้องรันผ่าน local server ก่อน เช่น:

```bash
cd pricetag-app
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

หรือใช้ VS Code extension "Live Server" ก็ได้เช่นกัน

## วิธีขึ้น GitHub Pages (ใช้งานจริง)

1. สร้าง repo ใหม่ (หรือใช้ repo เดิม) แล้ว push โฟลเดอร์ `pricetag-app/` ทั้งหมดเข้าไป
2. ไปที่ Settings → Pages → Source เลือก branch ที่ push ไว้ (เช่น `main`) และ folder `/ (root)`
   - ถ้าอยากเก็บรวมกับโปรเจกต์อื่นในโดเมนเดียว ให้ push เข้าโฟลเดอร์ย่อยแล้วปรับ path ตาม repo
3. รอ 1-2 นาที แล้วเข้าได้ที่ `https://<username>.github.io/<repo>/`

ไม่ต้องตั้งค่า build step ใดๆ เพราะเป็น static HTML/CSS/JS ล้วน

## สิ่งที่ทำได้ตอนนี้

- เลือกหมวดป้าย (ลดราคา / โปรโมชั่น / ขายดี / ใหม่) และขนาด (A3 ตั้ง, A3 นอน, A4 นอน, A5 นอน 2 ใบ/แผ่น)
- กรอกชื่อสินค้า, รายละเอียด, ราคา, ราคาปกติ, ช่วงวันที่ (หมวด ก/ข) — พรีวิวอัปเดตทันทีตามรูปแบบจริง
- เพิ่มป้ายหลายใบลงคิว แล้วพิมพ์รวดเดียวหลายหน้า
- กดพิมพ์แล้วตั้งขนาดกระดาษ (@page) ให้ตรงกับเทมเพลตอัตโนมัติ — ใช้เหมือนเว็บพิมพ์เอกสารทั่วไป (Ctrl+P)
- วันที่ที่กรอกจะแปลงเป็น พ.ศ. ให้อัตโนมัติ (เช่นเลือก 10 ก.ย. 2026 → แสดง 10/09/69)

## ข้อจำกัดที่ควรรู้

- **ขนาด A5 (2 ใบ/แผ่น)**: ตำแหน่งข้อความวัดจากรูปที่ render จริงแล้ว (ไม่ใช่ประมาณ) แต่ยังควรพิมพ์ทดสอบ 1 แผ่นเทียบกับเทมเพลตต้นฉบับก่อนใช้งานจริงจัง เผื่อต้องขยับเล็กน้อย
- ราคาใหม่/ราคาปกติ ต้องกรอกเองทุกครั้ง (ตามที่ตกลงไว้ — ไฟล์ stock ไม่มีคอลัมน์ราคาขาย)
- ยังไม่มีการเชื่อมไฟล์ StockReport.xlsx (ค้นหาสินค้าอัตโนมัติ) — เป็น phase ต่อไป

## เพิ่มเทมเพลตใหม่ในอนาคต

ดู **`ADDING_TEMPLATES.md`** — ระบบออกแบบให้เพิ่มหมวด/ขนาด/เทมเพลตใหม่ได้โดย
**ไม่ต้องแก้โค้ด** (แก้ที่ `data/templates.json` อย่างเดียว) และมีสคริปต์ใน
`tools/` ช่วยแปลงไฟล์ .docx ใหม่ให้อัตโนมัติเป็นส่วนใหญ่

## Phase ต่อไป (ยังไม่ได้ทำ)

1. อัปโหลด/ค้นหาสินค้าจาก StockReport.xlsx (ชื่อ, รหัส, รูป) มาเติมชื่อสินค้าอัตโนมัติ — ราคายังต้องกรอกเองอยู่ดี
2. ปรับตำแหน่งฟิลด์ A5 ให้ตรง 100% หลังพิมพ์ทดสอบจริง
3. (ถ้าต้องการ) เชื่อม Supabase ให้หลายสาขาใช้ชุดข้อมูล/เทมเพลตร่วมกัน หรือบันทึกประวัติการพิมพ์

## โครงสร้างไฟล์

```
pricetag-app/
├── index.html          หน้าเว็บหลัก
├── css/style.css        สไตล์ + การจัดวางสำหรับพิมพ์
├── js/app.js             ลอจิกทั้งหมด (เลือกเทมเพลต, ฟอร์ม, พรีวิว, คิว, พิมพ์)
├── data/templates.json   พิกัด/สี/ฟอนต์ของทุกช่องข้อความในทั้ง 16 เทมเพลต
├── assets/bg/            รูปพื้นหลังของแต่ละเทมเพลต (สกัดจากไฟล์ Word ต้นฉบับ)
└── fonts/                ฟอนต์ FC Vision Rounded (Regular, Bold, Heavy)
```

หากต้องแก้ตำแหน่ง/ขนาดตัวอักษรของช่องไหน แก้ได้ตรงใน `data/templates.json`
(หน่วยเป็น mm ทั้งหมด อ้างอิงจากมุมซ้ายบนของป้าย)
